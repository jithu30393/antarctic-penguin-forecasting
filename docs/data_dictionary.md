# Data dictionary
`colony_id`: stable colony identifier. `species`: species name. `latitude/longitude`: WGS84 coordinates. `survey_date`: observation date. `population_count`: observed count. `survey_method`: aerial/ground/drone fixture methods. `survey_quality`: high/medium/low. `sea_surface_temperature`: °C. `sea_ice_concentration`: 0–1 fraction. `air_temperature`: °C. `chlorophyll_concentration`: fixture concentration unit. `ocean_condition`: normalized environmental index. `source_id`: source/version marker. `observation_uncertainty`: count uncertainty. `time_delta`: days since prior observation for colony. `observation_mask`: 1 observed, 0 missing/padded.
