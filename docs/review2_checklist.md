# Review 2 evidence checklist
1. **SRS 10/10 evidence:** `docs/SRS.md`, traceability, API schemas, validation tests.
2. **Architecture 10/10 evidence:** architecture docs and UML/flow diagrams, backend/frontend separation.
3. **Algorithm 10/10 evidence:** baseline + hierarchical + ST-GNN + uncertainty + XAI in `src/`.
4. **Hardware/partial prototype 10/10 evidence:** `scripts/simulate_sensor.py`, `hardware/esp32_sensor_example` and live sensor UI concept.
5. **Modern tools/teamwork 10/10 evidence:** Git/GitHub-ready repo, Python, FastAPI, React, PyTorch, Docker, pytest, CI.
For each category demonstrate the corresponding command, API endpoint, artifact and test result; evaluator should use actual generated metrics rather than claimed target values.
